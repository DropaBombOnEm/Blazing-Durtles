# Blazing Durtles

Blazing Durtles is an Android app for WaniKani, forked from the existing codebase of Smouldering Durtles, the popular open-source client, but with some added features and QOL changes.

# Below are some of the added features and/or changes.

### • Added "**Daily Steaks**"
Increase by completing at least one review or lesson item per day.
Resets if you miss a day.
Example: "🔥 7". 

### • Added "**Daily Reviews Tracker**" 
Example: "**Reviews Completed Today: ___**"
Default = On. Disable in "**Dashboard Settings**"

### • Added "**Daily Lesson Tracker**"
Example: "**Lessons Completed Today: ___**"
Default = On. Disable in "**Dashboard Settings**"

### • Added option "**Katakana Input for On'yomi Kanji**"
Example: Typing in lowercase will automatically outout uppercase & katakana for On'yomi kanji reading questions.
Default = off. Enable in "**Lessons and Reviews Settings**". (This automation replaces the manual setting "**Require on'yomi readings in Katakana**")

### • Changed the format to how the level & time on level were displayed 
Example: "**Current Level: X | Time on Level: X Day/s**".
     
### • Removed decimals from "**Time on Level**".
Example: "**12.7 Days**" will show "**12 Days**" instead.
   
### • Changed the **date format** in the **Subject View** for "**Unlocked:** ", "**Started:** ", "**Passed:** " & "**Next Review:** " to ddd, MMM D, YYYY at --:--
Example: "**Unlocked: Tue, Oct 3rd, 2023 at 5:08 AM**".
"**Next Review:** " will show "**Available Now**" instead, _if it is currently available_.

### • Updated the **Review**/**Session Summary** to hide null values
You will no longer see "**[Type] Correct/Incorrect: 0**", as that row will be hidden. (Values of "1" or higher are shown normally)
You will now longer see "**Overall Percentage Correct/Incorrect: 0%**", as that section will be hidden. (The Overall Percentage with "100%" will be shown normally)
Added a blank row underneath "**Overall Percentage**" to give some space from item types.

### • Added **title case** across (most) menus
Example: **Menus Appear Like This**.
  
### • Reworded some menus and descriptions to be more clear
